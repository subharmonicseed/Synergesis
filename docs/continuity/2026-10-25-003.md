# 2026-10-25-003 — Recentrage sur la colonne vertébrale glyphique

**Catégorie : correction de cadrage et implémentation bornée. Statut : code enregistré ; tests non exécutés dans cette session.**

## Déclencheur

L'utilisateur rappelle que les glyphes ne sont pas un décor : leur fonction dans SYN est de lui permettre de retrouver le contexte, les transformations et leur provenance. L'assistant avait proposé une mémoire Git et un futur outil de récupération **sans se raccorder au système de glyphes déjà existant**.

Cette omission est une instance explicite du « verrouillage prématuré du cadre » : conception d'un outil neuf alors que l'architecture principale remplissait déjà une grande partie de la fonction.

## D007 — Les glyphes structurent le contexte

Conserver le Glyph Protocol v1 comme **unité d'identité, de relation, de révision et d'audit** :
`synergesis_glyph_protocol.py` (`GlyphLedger`, `GlyphAuditGraph`, `find_by_external_ref`, `upstream`, `downstream`, `supersedes`, `derived_from`).

GitHub sert de **source documentaire versionnée**, et non de substitut au graphe. Les journaux runtime et les mémoires personnelles ne sont pas publiés. Les glyphes servent la coopération SYN au sens large, sans assimiler celle-ci au code.

## Première application

- `synergesis_scene_glyph_bridge.py` : ancrages explicites vers cinq documents publics, glyphes `concept`/`decision`/`hypothesis`, références et empreintes documentaires, liens `derived_from`, révisions `supersedes`.
- `tests/test_scene_glyph_bridge.py` : cinq tests écrits pour la récupération, l'idempotence, les révisions et les conditions d'échec.
- `docs/SYN_GLYPH_SCENE_BRIDGE_V1.md` : commandes PowerShell et limites opérationnelles.

## Limites non négociables

Ceci n'est **pas** une preuve d'activation de la mémoire dans ChatGPT ni de récupération sémantique automatique. Le rappel se fait explicitement, après import sur une machine ayant les fichiers et un ledger privé. Aucun résultat de test n'a été vérifié ici. Le référentiel et les sources peuvent évoluer indépendamment ; l'adaptateur doit refuser de rappeler une source périmée comme si elle était actuelle.

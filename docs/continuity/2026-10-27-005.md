# 2026-10-27-005 — Prisme YouTube, prototype et limite de déploiement

Type : implémentation bornée et correction de portée. Statut : prototype, pas déploiement sur un poste utilisateur.
Base : `a4d38bd22d6751c2af509d577ac233cfb6493e4b`, branche de départ `feat/syn-glyph-scene-bridge-v1`.

## Décision et résultat

Publier un module navigateur autonome dans `apps/syn-prisme-youtube/`, sans modifier AEGIS/RISK/REALITY ni les glyphes. Ce module est un adaptateur de consultation YouTube, pas un nouveau système de mémoire conceptuelle SYN. Les traces locales de cartes visibles ne sont pas un historique de visionnage et ne sont jamais publiées.

Le panneau propose un classement lexical réglable et un bilan de concentration des chaînes. Le relais Python facultatif offre une analyse des textes disponibles, sans vérification web. Il reste désactivé par défaut et ne s'appuie pas sur une session ChatGPT existante. Les préférences publiques par défaut sont vides. Aucun profil personnel ni secret n'est publié.

## Vérifications et objections conservées

Dix tests Node et quatre tests Python ont été exécutés dans l'environnement Linux de développement. Les fournisseurs IA sont simulés. Les tests ne prouvent ni la qualité d'un modèle réel, ni le bon rendu sur YouTube. Le navigateur de test n'a pas pu être téléchargé. Le lanceur Windows est fourni mais non exécuté ici.

L'accès GitHub ne permet pas de contrôler un ordinateur personnel. Le lanceur copie les fichiers et ouvre la page des extensions ; la validation du navigateur reste une étape locale. Aucun déploiement sur poste ni appel payant n'est revendiqué.

## Conséquence

Faire le premier essai dans un vrai navigateur avant de qualifier le module d'opérationnel. Vérifier l'extraction, les réglages, la pause et les bases de l'analyse. Étendre ensuite à d'autres plateformes seulement avec une intégration explicite. Préserver D008 : le relais facultatif ne remplace pas le mode ChatGPT de SYN.
